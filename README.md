## 중등 평가 문항 제작기 사용법

1. **주문서·프롬프트**: 학년·과목·문항 수·배점·난이도 비율 입력. 국어는 응용 지침(프롬프트 2)이 자동으로 붙고, 다른 교과는 "프롬프트 3" 버튼으로 교과용 응용본을 만들 수 있습니다.
2. **자료 첨부**: 교과서 단원, 기존 평가지(문제+정답), 출제원안 양식. PDF·이미지·텍스트 지원(HWP는 PDF로 변환).
3. **출제**: Anthropic API 키를 넣고 "자료 분석 요청" → 보고 확인 → "출제 시작" → 문항 번호로 수정 요청. 결과는 Word(.doc)·마크다운·인쇄로 내보냅니다.
   API 키가 없으면 "프롬프트만 복사"로 Claude 대화창에 붙여 쓸 수 있습니다.

API 키는 브라우저에서 Anthropic API로만 전송되며, 저장을 선택한 경우에만 이 브라우저(localStorage)에 남습니다.
