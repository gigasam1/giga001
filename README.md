## 중등 평가 문항 제작기 사용법 (사회·역사·도덕)

1. **과목·학년·난이도**: 사회/역사/도덕(또는 기타)과 중1~3을 버튼으로 고르고, 난이도는 쉬움·보통·어려움 또는 상:중:하 비율을 직접 정합니다. 문항 수로 환산한 결과가 바로 보입니다. 교과별 응용 지침은 자동으로 들어갑니다.
2. **학습 내용·기존 틀**: 출제 범위와 이번 학습 자료(교과서·학습지)를 넣고, 기존 틀(지난 문제지, 이원목적분류표 양식, 서술형 답안·채점 기준 양식)을 올립니다. 기존 틀은 브라우저에 저장되어 다음 시험 때 다시 올리지 않아도 됩니다.
3. **자동 출제**: API 키를 넣고 "⚡ 자동 출제"를 누르면 기존 틀과 같은 형식으로 시험지·정답·서술형 답안·이원목적분류표·중복 점검 결과가 나옵니다. 이후 "시험 전체 난이도 ↑/↓"나 문항 번호로 수정을 요청합니다. 결과는 Word(.doc)·마크다운·인쇄로 내보냅니다.
   API 키가 없으면 "프롬프트만 복사"로 Claude 대화창에 붙여 쓸 수 있습니다.

API 키는 브라우저에서 Anthropic API로만 전송되며, 저장을 선택한 경우에만 이 브라우저(localStorage)에 남습니다.
