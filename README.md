## 중등 평가 문항 제작기 사용법 (사회·역사·도덕)

주소: https://exam-maker-zeta.vercel.app

1. **과목·학년·난이도**: 버튼으로 선택. 교과별 응용 지침 자동 적용.
2. **학습 내용·기존 틀**: 출제 범위와 학습 자료(PDF는 보낼 쪽만 지정 가능, HWPX 읽기 지원). 기존 틀은 브라우저에 저장되고, 파일로 내보내 동료와 주고받을 수 있습니다.
3. **출제·편집**: "⚡ 자동 출제" → 문항 카드에서 고정·수정·다시 만들기·순서 이동·삭제, 자동 검사(문항 수·배점 합계·난이도·정답 분포), AI 검토, A/B형, Word(.docx)·인쇄(2단)·마크다운 저장, 예상·실제 비용 표시.
4. **이력·문항 은행**: 출제할 때마다 자동 저장. 같은 과목의 이력·은행 문항은 다음 출제 때 중복 판정에 포함됩니다.

### 학교 공용 키 (선택)
Vercel 프로젝트 환경 변수에 `ANTHROPIC_API_KEY`(학교 키)와 `SCHOOL_PASSWORD`(선생님용 비밀번호)를 넣고 다시 배포하면, 선생님들은 비밀번호만으로 출제할 수 있습니다. 키는 서버(`exam-maker/api/anthropic.js`)에만 있고 브라우저로 내려가지 않습니다. 요청 한 번에 약 4MB까지 보낼 수 있으니 PDF 쪽 범위를 지정하세요. 비용 상한은 Anthropic 콘솔의 월 사용 한도로 관리합니다.

### 자동 배포 (GitHub 연결)
Vercel의 exam-maker 프로젝트 → Settings → Git에서 이 저장소를 연결하고 Root Directory를 `exam-maker`로 지정하면, 이후 변경이 자동으로 배포됩니다.

API 키는 브라우저에서 Anthropic API로만 전송되며, 저장을 선택한 경우에만 이 브라우저(localStorage)에 남습니다.
